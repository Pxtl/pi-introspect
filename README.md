# pi-introspect

pi-introspect is a package for pi coding agent that exposes self-reflection tools to the pi coding agent.  It provides tool(s) for the agent to find out its own model metadata (ID, thinking levels, provider URL, etc). The agent can view its current context window (and how much is used), its model length limit, its current thinking level and reasoning budget.  Like most tool packages, a brief skill is included for info on how to use the tools.

# dotnet

This project is built from Pxtl's standard dotnet template.  Since pi coding agent extensions are not written in dotnet, most dotnet-related content should be deleted or adapted to node typescript.
